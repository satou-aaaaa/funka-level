# 噴火警戒レベルよみ（funka-level）

噴火警戒レベル1〜5が出た場面で、登山する人・住む人がとる行動を選ぶ、1日5問の学習ゲーム。

- 遊ぶ: <https://satou-aaaaa.github.io/funka-level/>
- 答えは気象庁の資料（「噴火警戒レベルの説明」・リーフレット「噴火警報と噴火警戒レベル」・「噴火警報・予報の説明」）に基づく。
- 山の名前と場面はすべて架空。実在の火山の今のレベルは出さない。
- このゲームは防災の公式の情報の代わりではありません。本当の火山のレベル・規制の範囲・避難の情報は、気象庁と市町村の発表で確かめてください。
- 記録は遊ぶ人のブラウザ（localStorage）だけに残り、外へ送らない。外から読むのは文字（Google Fonts）だけ。
- 感想は画面の「感想を送る」から（GitHub の Issue フォーム。名前・メールは要りません）。
